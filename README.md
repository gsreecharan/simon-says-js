# Vanilla JS Simon Says Game

A fully interactive Simon Says memory game built with vanilla JavaScript, DOM manipulation, HTML5, and CSS3.

**Live Deployment:** https://gsreecharan.github.io/simon-says-js/

---

## Overview

This project is a web-based replica of the classic Simon Says memory game. It leverages vanilla JavaScript to handle core game logic, array-based sequence tracking, and asynchronous DOM manipulation. Features include randomized color flashing, strict user input validation, progressive difficulty scaling, and localized high-score tracking.

## Technical Stack

- **Frontend:** Vanilla JavaScript (ES6+)
- **Markup & Styling:** HTML5, CSS3
- **Deployment:** GitHub Pages
